  ✅  3. Clone Bookmarks / Presets       — CLI (rr preset save/list/run/remove), Desktop ekranı

  ✅ 14. REST API / Server Modu          — CLI (rr serve --port 8080), 6 endpoint, JDK HttpServer
  ✅  8. Package Registry                 — CLI (rr pkg push/pull/list/serve), Local + HTTP backend

  ✅ 15. Point-in-Time Clone              — CLI (rr clone --at "2026-06-01T10:00"), audit tablo stratejisi
  ✅ 16. İlişki Graf Editörü             — Drag & drop, collapse/expand, manuel FK çizme, ~/.recordrelay/graph-<conn>.json
